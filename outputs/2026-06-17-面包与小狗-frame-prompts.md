# 面包与小狗 — 单帧分镜画面提示词

> 目标平台：即梦 / 可灵 / Midjourney / Flux
> 画幅比例：16:9 横屏
> 视觉风格：3D 动画皮克斯质感，温暖治愈

## Frame 01 — 准备咬面包

### 8 要素分析

| 要素 | 内容 |
|------|------|
| Scene | 日落时分 · 户外空地 · 暖金色天空，远处树木剪影模糊 |
| Subject | 9-11 岁男孩，圆脸深棕圆杏眼，深棕黑短发刘海眉上，白T恤深蓝短裤，微驼背 |
| Action | 右手举圆形小面包至嘴边约 5cm，嘴微张准备咬下，动作自然日常，手指轻捏面包 |
| Camera | 中景 (MS) + 平视 + 定镜微缓推 |
| Composition | 三分法居中偏左，上半身入画，浅景深背景虚化 |
| Lighting | 主光：落日从左上 45° 射入（~3500K 暖金）。辅光：天空环境光柔化右侧阴影。轮廓光：逆光在发丝和肩膀边缘形成金色光边 |
| Mood | 平静专注 · 温暖日常 · 金色浸润 |
| Story Purpose | 建立情境——普通日常一幕，即将被打破 |

### Compressed Prompt

9-11岁男孩在日落空地上，右手举圆形小面包至嘴边约5cm，嘴微张准备咬下，白T恤深蓝短裤，深棕黑短发，暖金色夕阳从左上45°射入。中景，平视，定镜微缓推镜头感。三分法构图偏左，浅景深暖金虚化背景，发丝逆光金边。3D动画皮克斯质感，温暖治愈色调，高细节纹理，cinematic lighting，soft golden hour glow。--ar 16:9

## Frame 02 — 小狗悲伤凝视

### 8 要素分析

| 要素 | 内容 |
|------|------|
| Scene | 同一空地 · 男孩右侧约 2-3m · 小狗蹲坐地面 |
| Subject | 小黄狗，楔形头立耳微折，左耳尖浅色斑，暖土黄短毛奶油色腹，深琥珀圆眼 |
| Action | 完全静坐，头微仰，眼睛固定凝视面包方向（向左），上眼睑微下垂，大瞳孔，偶尔极轻微舔嘴 |
| Camera | 近景 (CU) + 平视（小狗视线高度）+ 定镜 |
| Composition | 居中偏右，负空间留左侧（凝视方向），浅景深暖金色散景背景 |
| Lighting | 主光：落日从左上射入（~3400K），在狗眼形成大而明亮的琥珀色高光。辅光：天空光柔化右侧。轮廓光：逆光勾勒狗耳边缘和吻部毛发 |
| Mood | 悲悯渴望 · 安静请求 · 大瞳孔湿润高光 |
| Story Purpose | 引入冲突——小狗的渴望与资源的稀缺 |

### Compressed Prompt

小黄狗蹲坐在草地上，头微仰，深琥珀色圆眼固定凝视左方向，上眼睑微下垂大瞳孔湿润高光，左耳尖浅色斑明显，暖土黄短毛奶油色腹，尾巴静止环在爪旁，暖金色虚化散景背景。近景，平视视线高度，定镜。居中偏右构图，负空间留左。逆光勾勒耳缘和吻部，眼中有大而亮的琥珀色高光。3D动画皮克斯质感，温暖治愈色调，高细节毛发纹理，cinematic lighting。--ar 16:9

## Frame 03 — 掰面包特写

### 8 要素分析

| 要素 | 内容 |
|------|------|
| Scene | 男孩手部 · 画面极虚化暖金色模糊光斑背景 |
| Subject | 儿童双手，手指纤细圆润，指甲干净短小，白T恤袖口隐约可见 |
| Action | 双手拇指各按面包一侧，正缓慢向两侧用力掰开，面包从中断裂，细小碎屑在逆光中飘落呈金色光点 |
| Camera | 超特写 (ECU) + 微俯 45° + 定镜 |
| Composition | 居中构图，极浅景深，只有手和面包在焦点内 |
| Lighting | 主光：落日逆光从画面上方偏左射入（~3200K）。逆光穿透碎屑产生丁达尔效应体积光，碎屑呈半透明金色光点 |
| Mood | 内心挣扎→决断 · 仪式感 · 金色视觉诗 |
| Story Purpose | 转折时刻——决定性的分享动作 |

### Compressed Prompt

儿童双手超特写，手指纤细圆润，拇指各按圆形面包一侧缓慢向两侧掰开，面包裂口处细小碎屑在逆光中飘落呈半透明金色光点，白T恤袖口隐约，暖金色虚化光斑背景。超特写，微俯45°视角，定镜。居中构图，极浅景深。落日逆光从上方偏左射入，丁达尔效应体积光穿透碎屑。3D动画皮克斯质感，高细节纹理，cinematic macro shot。--ar 16:9

## Frame 04 — 递出面包

### 8 要素分析

| 要素 | 内容 |
|------|------|
| Scene | 中近景 · 半身 · 画面右侧边缘可见小狗模糊轮廓 |
| Subject | 男孩完整面部，表情温和，目光从面包转向右侧 |
| Action | 右手缓缓从胸前向右前方伸出，掌心向上托着半块面包，手臂运动缓慢稳定，身体微前倾，嘴角微动 |
| Camera | 中近景 (MCU) + 平视 + 缓推 |
| Composition | 三分法——男孩在左 2/3，面包在画面中央偏右为视觉焦点，小狗模糊轮廓在右侧边缘 |
| Lighting | 主光：落日从左上射入（~3000K 暖金），面包被金光照亮，皮肤暖调 |
| Mood | 善意温柔 · 犹豫后的坚定 · 金色温暖 |
| Story Purpose | 善意表达——分享的邀请 |

### Compressed Prompt

男孩上半身中近景，右手从胸前向右前方伸出掌心向上托半块面包，目光柔和从面包转向右侧，嘴角微动身体微前倾，白T恤深蓝短裤，深棕黑短发，右侧边缘可见小狗模糊轮廓。中近景，平视，缓推镜头感。三分法构图男孩在左2/3，面包为画面中央视觉焦点。暖金落日从左上照亮面包和皮肤。3D动画皮克斯质感，温暖治愈，cinematic lighting，浅景深。--ar 16:9

## Frame 05 — 小狗接面包

### 8 要素分析

| 要素 | 内容 |
|------|------|
| Scene | 近景 · 小狗为主体 · 男孩手从画面左侧边缘伸入托面包 |
| Subject | 小黄狗全身近景，从坐姿变站立，尾巴在叼走瞬间抬起慢摇 |
| Action | 看面包→看左上方男孩确认安全→前腿迈半步→停顿→再迈半步→轻轻叼走面包 |
| Camera | 近景 (CU) + 平视（小狗高度）+ 定镜 |
| Composition | 三分法——小狗在画面中右位置，男孩手从左侧伸入，面包在画面中央 |
| Lighting | 主光：落日从左上射入（~2800K 浓金），奶油色腹毛被照亮，狗眼高光 |
| Mood | 试探→接受→感激 · 浓金色温暖 |
| Story Purpose | 接受善意——跨物种信任建立 |

### Compressed Prompt

小黄狗近景站立，从坐姿变为前迈半步姿态，头部向画面中央半块面包靠近，尾巴抬起慢摇，左耳尖浅色斑可见，暖土黄短毛奶油色腹，男孩右手从画面左侧边缘伸入托着面包。近景，平视小狗视线高度，定镜。三分法构图小狗在右，面包在中央。浓金落日从左上射入（2800K），照亮奶油色腹毛和狗眼高光。3D动画皮克斯质感，高细节毛发，cinematic golden hour。--ar 16:9

## Frame 06 — 男孩抚摸小狗

### 8 要素分析

| 要素 | 内容 |
|------|------|
| Scene | 中景 · 并排坐 · 夕阳更低天空暖金→琥珀 · 长影子 |
| Subject | 男孩在左 1/3，小狗在右 1/3，间距约 10cm |
| Action | 男孩右手放小狗背上从肩胛向后背缓慢抚摸，肩部放松；小狗身体靠向男孩腿，耳朵放松前倾，尾巴持续慢摇 |
| Camera | 中景 (MS) + 平视 + 微环绕 ~15° |
| Composition | 三分法——男孩左 1/3，小狗右 1/3，中间连接处为视觉焦点 |
| Lighting | 主光：落日更低位（~2800K 琥珀金），影子更长更柔，温暖包裹感 |
| Mood | 温暖亲密 · 陪伴感 · 琥珀金光 |
| Story Purpose | 情感升温——从施与受转为平等陪伴 |

### Compressed Prompt

男孩和小狗并排坐在草地上，男孩在左1/3右手放小狗背上轻轻抚摸，小狗在右1/3身体靠向男孩腿尾巴慢摇，耳朵放松前倾，白T恤深蓝短裤，暖土黄小黄狗，间距约10cm。中景，平视，微环绕镜头感。三分法构图，低斜暖夕阳拉出长影子。琥珀金落日（2800K）温暖包裹。3D动画皮克斯质感，治愈温馨，cinematic lighting，soft warm tones。--ar 16:9

## 使用说明

- 每条 **Compressed Prompt** 可直接粘贴到即梦/可灵/Midjourney/Flux
- 16:9 画幅：MJ 用 `--ar 16:9`，即梦/可灵在参数中设置横屏
- 如需更高角色一致性，可先使用 Frame 01（男孩）和 Frame 02（小狗）生成角色参考图，后续镜头用图生图模式
